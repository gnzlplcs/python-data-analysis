# Python Data Analysis

Personal notes, coding challenges, and practical exercises from the LinkedIn Learning course **Python Data Analysis** by **Michele Vallisneri**.

## Course Overview

- **Platform:** LinkedIn Learning
- **Instructor:** Michele Vallisneri (Professor of Gravitational Physics, ETH Zurich)
- **Level:** Intermediate | **Duration:** 3h 43m

## Learning Objectives

- **Python Data Structures:** Use tuples, lists, dictionaries, sets, comprehensions, `defaultdict`, and data classes effectively.
- **Numerical Computing (NumPy):** Create and index arrays, perform vectorized mathematical operations, work with specialized arrays (records and dates), and leverage the NumPy ecosystem.
- **Structured Data (pandas):** Build and manipulate Series and DataFrames, apply indexing, execute math and plotting operations, and perform database-style operations.
- **Data Wrangling & Preprocessing:** Import, clean, filter, reshape, tidy, and simulate datasets, as well as link and merge multiple data sources.
- **Exploratory Analysis & Visualization:** Summarize quantitative and categorical variables, visualize distributions, compare features, and build interactive dashboards using **Plotly** and **Dash**.

## Projects & Hands-on Practice

1. **Finding Anagrams:** Applying native Python data structures to solve text-matching logic.
2. **Weather Patterns (NumPy):** Identifying and visualizing historical climate trends.
3. **Baby Names Popularity (pandas):** Analyzing a century of demographic naming data.

## Local Setup & Workflow

- **Environment:** WSL (Ubuntu) + VS Code + Python 3
- **Core Libraries:** NumPy, pandas, Plotly, Dash
- **Exercise Files:** Adapted from the official course GitHub repository for local practice.
